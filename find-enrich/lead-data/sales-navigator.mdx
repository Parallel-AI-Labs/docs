If you already know how to build a good search in Sales Navigator, this page turns that search into contacts in a [Smart List](/find-enrich/smart-lists). You don't need to connect a LinkedIn account, and nothing runs through your own login.

## Two Ways to Search

### Paste a search URL

Build the search in Sales Navigator as you normally would, then copy the URL from your browser and paste it into **Sales Navigator search URL**.

The URL must contain `linkedin.com/sales/` — a regular LinkedIn search or a company page won't work.

### Build a search

If you'd rather not leave the platform, use the **Build a search** tab and set the filters directly:

- **Job title**
- **Location**
- **Current company**
- **School**
- **Keywords**

Set at least one. Filters combine, so each one you add narrows the search to a smaller, higher-quality set of leads.

## Running the Search

1. Select your company from the sidebar
2. Go to **Lead Data** → **Sales Navigator**
3. Paste a URL or set your filters
4. Set **Maximum leads to find** — anywhere from 1 to 500
5. Click **Search**

Larger searches take a few minutes. The results are saved as soon as the search finishes, so you can leave the page and reopen it later from **Recent searches**.

## Saving Results

Select the leads you want and click **Add to Smart List**. You can pick an existing list or type a new list name and create it on the spot.

People already on the list are matched on their LinkedIn URL and enriched in place, so re-running a search doesn't create duplicate rows.

## Credits

Sales Navigator uses **1 data credit per lead the search returns**, whether or not you add it to a list. A search that matches nobody is free.

Because the cost follows the result count, the **Maximum leads to find** slider is also your budget control. See [Credits](/find-enrich/lead-data/lead-credits).

## Tips

1. **Cap the maximum while testing.** Run 10 leads to check the search is right before running 500.
2. **Narrow with filters, not volume.** A tight search of 50 good leads beats 500 loose ones you'll never contact.
3. **Reuse past searches.** **Recent searches** keeps your results — no need to pay for the same search twice.
