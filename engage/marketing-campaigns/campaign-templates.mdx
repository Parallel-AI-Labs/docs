A template stores the parts of a [marketing campaign](/engage/marketing-campaigns) that stay the same every time — the layout, the styling, the default list and sender — leaving only the actual message to write.

## The `{{content}}` Placeholder

A template is a complete email with one hole in it. Put `{{content}}` where the per-campaign message should go, and everything around it — header, footer, styling, unsubscribe — is reused on every send.

That's the whole idea: design the wrapper once, write only the middle each time.

## Creating a Template

1. Select your company from the sidebar
2. Go to **Marketing Campaigns** → **Templates**
3. Click **New Template**
4. Fill in:
   - **Name** and **Description** — how you'll recognize it later
   - **Subject** — a default subject line
   - **Default List** — the Smart List campaigns usually go to
   - **Default Sender** — the sender profile to send from
   - The email body, with `{{content}}` where the message belongs
5. Save

The defaults are starting points, not locks — you can change the list or sender on any individual campaign.

## Using a Template

From a template's menu, choose **Use template**. The campaign form opens with the template's styling and defaults already applied, ready for you to write the message and send.

You can also **Edit** or **Delete** a template from the same menu.

## Tips

1. **Build one good template first.** A single well-designed wrapper used consistently beats five half-finished ones.
2. **Put everything recurring in the template** — logo, footer, social links, unsubscribe. If you retype it each campaign, it belongs here.
3. **Set the defaults you actually use.** Filling in the usual list and sender removes two decisions per send.
4. **Send yourself a test** after editing a template, before it goes to a real list.
