Permanently deletes an agent and all of its associated data, including channel configurations, lead field definitions, and branding settings. Active conversations linked to the agent will no longer be handled. Use this endpoint with care.

<Warning>
  Deleting an agent is **permanent and cannot be undone**. All configuration, channel settings, and associated data for the agent will be immediately and irreversibly removed. If you only want to stop the agent from responding temporarily, consider setting `isActive` to `false` via [Update Agent](/api-reference/agents/update) instead.
</Warning>

## Endpoint

```
DELETE https://api.parallellabs.app/api/v0/agents/{agentId}
```

## Path Parameters

<ParamField path="agentId" type="string" required>
  The unique identifier of the agent to delete (e.g. `agent_abc123`). You can find agent IDs in the response from [List Agents](/api-reference/agents/list).
</ParamField>

## Response

Returns `200 OK` with a confirmation message on success.

<ResponseField name="msg" type="string">
  A human-readable confirmation that the agent was deleted. Value is always `"Agent deleted successfully"`.
</ResponseField>

## Example Request

```bash
curl -X DELETE https://api.parallellabs.app/api/v0/agents/agent_abc123 \
  -H "X-API-Key: YOUR_API_KEY"
```

## Example Response

```json
{
  "msg": "Agent deleted successfully"
}
```

## Errors

| Status | Description |
|--------|-------------|
| `401 Unauthorized` | Your API key is missing or invalid. |
| `403 Forbidden` | You do not have permission to delete this agent. |
| `404 Not Found` | No agent with the given `agentId` exists in your company. |
| `500 Internal Server Error` | An unexpected server error occurred. |
