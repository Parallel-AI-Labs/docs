Updates the configuration of an existing agent. This is a partial update — you only need to include the fields you want to change. Any fields you omit will retain their current values. Use this endpoint to update prompts, toggle channels, adjust knowledge base settings, or change branding options without resending the full agent object.

## Endpoint

```
PUT https://api.parallellabs.app/api/v0/agents/{agentId}
```

## Path Parameters

<ParamField path="agentId" type="string" required>
  The unique identifier of the agent to update (e.g. `agent_abc123`).
</ParamField>

## Request Body

Send a JSON object with `Content-Type: application/json`. All fields are optional — include only what you want to change.

<ParamField body="name" type="string">
  New display name for the agent.
</ParamField>

<ParamField body="systemPrompt" type="string">
  Updated system-level instructions for the agent's persona and behavior.
</ParamField>

<ParamField body="agentPrompt" type="string">
  Updated agent-specific prompt layered on top of the system prompt.
</ParamField>

<ParamField body="model" type="string">
  Change the AI model powering this agent (e.g. `gpt-4o`, `gpt-4o-mini`).
</ParamField>

<ParamField body="isActive" type="boolean">
  Set to `false` to deactivate the agent and stop it from accepting new conversations.
</ParamField>

<ParamField body="channelSettings" type="object">
  Updated channel configuration. You can include only the channels you want to modify.

  <Expandable title="channelSettings fields">
    <ParamField body="website" type="object">
      <Expandable title="website fields">
        <ParamField body="enabled" type="boolean">
          Enable or disable the website chat widget for this agent.
        </ParamField>
      </Expandable>
    </ParamField>

    <ParamField body="email" type="object">
      <Expandable title="email fields">
        <ParamField body="enabled" type="boolean">
          Enable or disable the email channel.
        </ParamField>
        <ParamField body="address" type="string">
          Update the email address assigned to this agent.
        </ParamField>
      </Expandable>
    </ParamField>

    <ParamField body="sms" type="object">
      <Expandable title="sms fields">
        <ParamField body="enabled" type="boolean">
          Enable or disable the SMS channel.
        </ParamField>
        <ParamField body="phoneNumber" type="string">
          Update the phone number assigned to this agent in E.164 format.
        </ParamField>
      </Expandable>
    </ParamField>

    <ParamField body="voice" type="object">
      <Expandable title="voice fields">
        <ParamField body="enabled" type="boolean">
          Enable or disable the voice channel.
        </ParamField>
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="knowledgeBaseEnabled" type="boolean">
  Toggle knowledge base search on or off for this agent.
</ParamField>

<ParamField body="knowledgeBaseScope" type="string">
  Update the knowledge base folder path this agent is limited to.
</ParamField>

<ParamField body="multiStepToolsEnabled" type="boolean">
  Enable or disable multi-step tool chaining for this agent.
</ParamField>

<ParamField body="multiStepMaxTurns" type="integer">
  Update the maximum number of tool-calling turns allowed per interaction. Must be between `1` and `10`.
</ParamField>

<ParamField body="aiContactCaptureEnabled" type="boolean">
  Toggle automatic contact information extraction on or off.
</ParamField>

<ParamField body="leadFields" type="array">
  Replace the agent's lead capture field definitions. Each element must include `name` (string), `type` (`"text"` | `"email"` | `"phone"` | `"number"`), and optionally `required` (boolean).
</ParamField>

<ParamField body="contactListId" type="string">
  Update the Smart List ID where captured contacts are added.
</ParamField>

<ParamField body="customColors" type="object">
  Update the brand colors for the chat widget. Provide any combination of `primary`, `secondary`, and `background` hex color strings.
</ParamField>

<ParamField body="avatarImage" type="string">
  New avatar image as a URL or base64-encoded data URI.
</ParamField>

## Response

Returns `200 OK` with the complete, updated agent object reflecting all current field values (not just the fields you changed).

<ResponseField name="id" type="string">
  Unique identifier for the agent.
</ResponseField>

<ResponseField name="name" type="string">
  Updated display name.
</ResponseField>

<ResponseField name="systemPrompt" type="string">
  Current system prompt after the update.
</ResponseField>

<ResponseField name="model" type="string">
  Current AI model assigned to the agent.
</ResponseField>

<ResponseField name="isActive" type="boolean">
  Current active status.
</ResponseField>

<ResponseField name="knowledgeBaseEnabled" type="boolean">
  Current knowledge base search setting.
</ResponseField>

<ResponseField name="shortCode" type="string">
  Short code for embeddable widgets (unchanged by updates).
</ResponseField>

<ResponseField name="created" type="integer">
  Unix timestamp (milliseconds) when the agent was originally created.
</ResponseField>

<ResponseField name="updated" type="integer">
  Unix timestamp (milliseconds) reflecting the time of this update.
</ResponseField>

## Example Request

The following example updates the agent's system prompt and enables the SMS channel with an assigned phone number:

```bash
curl -X PUT https://api.parallellabs.app/api/v0/agents/agent_abc123 \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "systemPrompt": "You are an expert customer support agent. Be concise, empathetic, and always offer a next step.",
    "channelSettings": {
      "sms": {
        "enabled": true,
        "phoneNumber": "+15550001234"
      }
    }
  }'
```

## Errors

| Status | Description |
|--------|-------------|
| `400 Bad Request` | One or more request body parameters are invalid. |
| `401 Unauthorized` | Your API key is missing or invalid. |
| `403 Forbidden` | You do not have permission to modify this agent. |
| `404 Not Found` | No agent with the given `agentId` exists in your company. |
| `500 Internal Server Error` | An unexpected server error occurred. |
