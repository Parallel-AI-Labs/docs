Update the metadata of an existing smart list. You can change the list's name, description, or both in a single request. Only the fields you include in the request body will be updated — omitting a field leaves it unchanged. Contact data within the list is not affected by this operation.

**Base URL:** `https://api.parallellabs.app`

**Authentication:** Include your API key in the `X-API-Key` header on every request.

---

## Request

**`PUT /api/v0/smart-lists/{listId}`**

### Path Parameters

<ParamField path="listId" type="string" required>
  The unique identifier of the smart list to update.
</ParamField>

### Request Body

<ParamField body="name" type="string">
  The new display name for the smart list. Must be a non-empty string if provided.
</ParamField>

<ParamField body="description" type="string">
  The new description for the smart list. Pass an empty string to clear an existing description.
</ParamField>

---

## Response

### 200 — Success

Returns the fully updated smart list object reflecting the changes.

<ResponseField name="id" type="string">
  The unique identifier of the smart list.
</ResponseField>

<ResponseField name="name" type="string">
  The updated display name of the smart list.
</ResponseField>

<ResponseField name="description" type="string">
  The updated description of the smart list.
</ResponseField>

<ResponseField name="contactCount" type="integer">
  The total number of contacts currently in this list. This value is unchanged by an update operation.
</ResponseField>

<ResponseField name="created" type="string">
  ISO 8601 timestamp indicating when the list was originally created.
</ResponseField>

<ResponseField name="updated" type="string">
  ISO 8601 timestamp indicating when the list was last updated. Reflects the time of this request.
</ResponseField>

```json Example Response
{
  "id": "sl_01hx9abc123",
  "name": "Hot Leads Q1 (Archived)",
  "description": "Q1 campaign leads — archived after campaign close.",
  "contactCount": 142,
  "created": "2024-01-15T09:00:00Z",
  "updated": "2024-04-01T10:00:00Z"
}
```

### Error Responses

| Status | Meaning |
|--------|---------|
| `400`  | Invalid request — the request body contains malformed or invalid field values. |
| `401`  | Authentication failed — your `X-API-Key` is missing or invalid. |
| `403`  | Forbidden — you do not have permission to update this smart list. |
| `404`  | Not found — no smart list exists with the provided `listId`. |
| `500`  | Internal server error — something went wrong on our end. |

All errors return a JSON body: `{"error": "descriptive message"}`

---

## Example

### Update a Smart List (cURL)

```bash
curl -X PUT https://api.parallellabs.app/api/v0/smart-lists/sl_01hx9abc123 \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "name": "Hot Leads Q1 (Archived)",
    "description": "Q1 campaign leads — archived after campaign close."
  }'
```
