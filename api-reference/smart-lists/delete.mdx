Permanently delete a smart list and all contact data it contains. If the list is currently linked to an agent via `contactListId`, the agent will stop collecting contacts into this list after deletion. Use this endpoint with caution — there is no way to recover a deleted list or its contacts.

**Base URL:** `https://api.parallellabs.app`

**Authentication:** Include your API key in the `X-API-Key` header on every request.

<Warning>
  **This action is permanent.** Deleting a smart list immediately and irreversibly destroys the list and all associated contact data. There is no confirmation step and no way to undo this operation. If you only want to stop using a list temporarily, consider updating its name to indicate it is inactive instead of deleting it.
</Warning>

---

## Request

**`DELETE /api/v0/smart-lists/{listId}`**

### Path Parameters

<ParamField path="listId" type="string" required>
  The unique identifier of the smart list to delete.
</ParamField>

---

## Response

### 200 — Success

Returns a confirmation message indicating the list was deleted.

<ResponseField name="msg" type="string">
  A confirmation string. Always `"List deleted"` on success.
</ResponseField>

```json Example Response
{
  "msg": "List deleted"
}
```

### Error Responses

| Status | Meaning |
|--------|---------|
| `401`  | Authentication failed — your `X-API-Key` is missing or invalid. |
| `403`  | Forbidden — you do not have permission to delete this smart list. |
| `404`  | Not found — no smart list exists with the provided `listId`. |

All errors return a JSON body: `{"error": "descriptive message"}`

---

## Example

### Delete a Smart List (cURL)

```bash
curl -X DELETE https://api.parallellabs.app/api/v0/smart-lists/sl_01hx9abc123 \
  -H "X-API-Key: YOUR_API_KEY"
```
