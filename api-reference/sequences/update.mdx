Update an existing outreach sequence's metadata, status, or steps. Only the fields you include in the request body will be modified — all other fields remain unchanged. You can use this endpoint to rename a sequence, update its step content, pause or resume it, or replace the entire steps array.

**Base URL:** `https://api.parallellabs.app`

**Authentication:** Include your API key in the `X-API-Key` header on every request.

---

## Request

**`PUT /api/v0/sequences/{sequenceId}`**

### Path Parameters

<ParamField path="sequenceId" type="string" required>
  The unique identifier of the sequence to update.
</ParamField>

### Request Body

<ParamField body="name" type="string">
  A new display name for the sequence.
</ParamField>

<ParamField body="description" type="string">
  A new description for the sequence. Pass an empty string to clear the existing description.
</ParamField>

<ParamField body="status" type="string">
  The new status for the sequence. One of `"draft"`, `"active"`, or `"paused"`. Set to `"active"` to start sending enrolled contacts through the sequence; set to `"paused"` to temporarily suspend delivery.
</ParamField>

<ParamField body="steps" type="array">
  A replacement array of step objects. When provided, this **replaces the entire existing steps array** — it is not merged. Omit this field to leave the steps unchanged.

  <Expandable title="Sequence step object">
    <ParamField body="type" type="string">
      The channel for this step. One of `"email"` or `"sms"`.
    </ParamField>
    <ParamField body="delayDays" type="integer">
      The number of days to wait after the previous step (or after enrollment) before sending.
    </ParamField>
    <ParamField body="subject" type="string">
      The email subject line. Required when `type` is `"email"`.
    </ParamField>
    <ParamField body="body" type="string">
      The message body content.
    </ParamField>
  </Expandable>
</ParamField>

---

## Response

### 200 — Success

Returns the fully updated sequence object.

<ResponseField name="id" type="string">
  The unique identifier of the sequence.
</ResponseField>

<ResponseField name="name" type="string">
  The updated display name of the sequence.
</ResponseField>

<ResponseField name="description" type="string">
  The updated description of the sequence.
</ResponseField>

<ResponseField name="status" type="string">
  The updated status of the sequence.
</ResponseField>

<ResponseField name="steps" type="array">
  The updated ordered array of step objects.
</ResponseField>

<ResponseField name="created" type="string">
  ISO 8601 timestamp of when the sequence was originally created.
</ResponseField>

<ResponseField name="updated" type="string">
  ISO 8601 timestamp of when the sequence was last updated. Reflects the time of this request.
</ResponseField>

### Error Responses

| Status | Meaning |
|--------|---------|
| `400`  | Invalid request — a provided field value is malformed or an invalid `status` value was used. |
| `401`  | Authentication failed — your `X-API-Key` is missing or invalid. |
| `403`  | Forbidden — you do not have permission to update this sequence. |
| `404`  | Not found — no sequence exists with the provided `sequenceId`. |
| `500`  | Internal server error — something went wrong on our end. |

All errors return a JSON body: `{"error": "descriptive message"}`

## Example

### Pause a Sequence (cURL)

```bash
curl -X PUT https://api.parallellabs.app/api/v0/sequences/seq_01hx9abc123 \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "status": "paused"
  }'
```
