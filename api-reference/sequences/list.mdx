Outreach sequences let you automate multi-step email and SMS campaigns for lead nurturing. This endpoint returns all sequences associated with your company in a paginated response, including their current status and step configuration. You can use the returned `id` values to retrieve, update, or delete individual sequences.

**Base URL:** `https://api.parallellabs.app`

**Authentication:** Include your API key in the `X-API-Key` header on every request.

---

## Request

**`GET /api/v0/sequences`**

### Query Parameters

<ParamField query="page" type="integer" default="1">
  The page number to retrieve. Use together with `pageSize` to paginate through large result sets.
</ParamField>

<ParamField query="pageSize" type="integer" default="10">
  The number of sequences to return per page. Maximum value is `100`.
</ParamField>

<ParamField query="search" type="string">
  An optional search string to filter sequences by name. The search is case-insensitive and matches any sequence whose name contains the provided value.
</ParamField>

---

## Response

### 200 — Success

<ResponseField name="items" type="array">
  An array of sequence objects for the requested page.

  <Expandable title="Sequence object">
    <ResponseField name="id" type="string">
      The unique identifier for this sequence.
    </ResponseField>
    <ResponseField name="name" type="string">
      The display name of the sequence.
    </ResponseField>
    <ResponseField name="description" type="string">
      An optional description providing context for the sequence.
    </ResponseField>
    <ResponseField name="status" type="string">
      The current status of the sequence. Common values include `"active"`, `"paused"`, and `"draft"`.
    </ResponseField>
    <ResponseField name="steps" type="array">
      An ordered array of step objects that make up the sequence. Each step defines a message to send and the timing for delivery.
    </ResponseField>
    <ResponseField name="created" type="string">
      ISO 8601 timestamp indicating when the sequence was created.
    </ResponseField>
    <ResponseField name="updated" type="string">
      ISO 8601 timestamp indicating when the sequence was last updated.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="integer">
  The total number of sequences matching the query (across all pages).
</ResponseField>

<ResponseField name="pages" type="integer">
  The total number of pages available given the current `pageSize`.
</ResponseField>

<ResponseField name="hasNext" type="boolean">
  `true` if there is at least one more page of results after the current page.
</ResponseField>

### Error Responses

| Status | Meaning |
|--------|---------|
| `401`  | Authentication failed — your `X-API-Key` is missing or invalid. |
| `403`  | Forbidden — you do not have permission to access sequences. |
| `500`  | Internal server error — something went wrong on our end. |

All errors return a JSON body: `{"error": "descriptive message"}`

## Example

### List Sequences (cURL)

```bash
curl "https://api.parallellabs.app/api/v0/sequences?page=1&pageSize=10" \
  -H "X-API-Key: YOUR_API_KEY"
```

### With Search Filter (cURL)

```bash
curl "https://api.parallellabs.app/api/v0/sequences?search=Welcome&pageSize=25" \
  -H "X-API-Key: YOUR_API_KEY"
```
