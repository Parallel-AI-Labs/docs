---

Create a new outreach sequence to automate your lead nurturing campaigns. You can define the sequence's steps at creation time or add them later via the update endpoint. Each step in the sequence specifies the channel (email or SMS), the message content, and the delay before it is sent relative to the previous step.

**Base URL:** `https://api.parallellabs.app`

**Authentication:** Include your API key in the `X-API-Key` header on every request.

---

## Request

**`POST /api/v0/sequences`**

### Request Body

<ParamField body="name" type="string" required>
  The display name for the new sequence. Choose a descriptive name that reflects the campaign's goal, such as `"Trial Onboarding"` or `"Re-engagement Campaign"`.
</ParamField>

<ParamField body="description" type="string">
  An optional description providing additional context about the sequence's purpose, target audience, or associated campaign.
</ParamField>

<ParamField body="steps" type="array">
  An optional ordered array of step objects that define the automated messages in this sequence. You can also add or update steps later using the [Update Sequence](/api-reference/sequences/update) endpoint.

  <Expandable title="Sequence step object">
    <ParamField body="type" type="string">
      The channel for this step. One of `"email"` or `"sms"`.
    </ParamField>
    <ParamField body="delayDays" type="integer">
      The number of days to wait after the previous step (or after enrollment for the first step) before sending this message.
    </ParamField>
    <ParamField body="subject" type="string">
      The email subject line. Required when `type` is `"email"`.
    </ParamField>
    <ParamField body="body" type="string">
      The message body. Used for the email body or SMS text content.
    </ParamField>
  </Expandable>
</ParamField>

---

## Response

### 201 — Created

Returns the newly created sequence object.

<ResponseField name="id" type="string">
  The unique identifier for the newly created sequence.
</ResponseField>

<ResponseField name="name" type="string">
  The display name of the sequence.
</ResponseField>

<ResponseField name="description" type="string">
  The description of the sequence, as provided in the request.
</ResponseField>

<ResponseField name="status" type="string">
  The initial status of the sequence. Newly created sequences are set to `"draft"`.
</ResponseField>

<ResponseField name="steps" type="array">
  The ordered array of step objects as provided in the request. Empty array if no steps were specified.
</ResponseField>

<ResponseField name="created" type="string">
  ISO 8601 timestamp indicating when the sequence was created.
</ResponseField>

<ResponseField name="updated" type="string">
  ISO 8601 timestamp indicating when the sequence was last updated.
</ResponseField>

```json Example Response
{
  "id": "seq_01hx9abc123",
  "name": "Trial Onboarding",
  "description": "Three-step onboarding sequence for new trial users.",
  "status": "draft",
  "steps": [
    {"type": "email", "delayDays": 0, "subject": "Welcome to Parallel AI", "body": "Thanks for signing up..."},
    {"type": "email", "delayDays": 3, "subject": "Here are your next steps", "body": "Ready to build your first agent?"},
    {"type": "sms",   "delayDays": 7, "body": "Hey! Need help getting started? Reply and we'll connect you with our team."}
  ],
  "created": "2024-04-01T08:00:00Z",
  "updated": "2024-04-01T08:00:00Z"
}
```

### Error Responses

| Status | Meaning |
|--------|---------|
| `400`  | Invalid request — the `name` field is missing or a step object is malformed. |
| `401`  | Authentication failed — your `X-API-Key` is missing or invalid. |
| `403`  | Forbidden — you do not have permission to create sequences. |
| `500`  | Internal server error — something went wrong on our end. |

All errors return a JSON body: `{"error": "descriptive message"}`

## Example

### Create a Sequence (cURL)

```bash
curl -X POST https://api.parallellabs.app/api/v0/sequences \
  -H "Content-Type: application/json" \
  -H "X-API-Key: YOUR_API_KEY" \
  -d '{
    "name": "Trial Onboarding",
    "description": "Three-step onboarding sequence for new trial users.",
    "steps": [
      {
        "type": "email",
        "delayDays": 0,
        "subject": "Welcome to Parallel AI",
        "body": "Thanks for signing up! Here is how to get started..."
      },
      {
        "type": "email",
        "delayDays": 3,
        "subject": "Here are your next steps",
        "body": "Ready to build your first agent? Follow this guide..."
      },
      {
        "type": "sms",
        "delayDays": 7,
        "body": "Hey! Need help getting started? Reply and we will connect you with our team."
      }
    ]
  }'
```
