title: "Delete Sequence — DELETE /api/v0/sequences/{sequenceId}"

---

Permanently delete an outreach sequence and all of its step configuration. If the sequence is currently active, it will be stopped immediately and no further messages will be sent to enrolled contacts. This action cannot be undone.

**Base URL:** `https://api.parallellabs.app`

**Authentication:** Include your API key in the `X-API-Key` header on every request.

<Warning>
  **This action is permanent.** Deleting a sequence immediately stops all message delivery for contacts currently enrolled in it. The sequence configuration and step data are permanently destroyed and cannot be recovered. If you want to suspend delivery without losing configuration, consider updating the sequence's `status` to `"paused"` instead.
</Warning>

---

## Request

**`DELETE /api/v0/sequences/{sequenceId}`**

### Path Parameters

<ParamField path="sequenceId" type="string" required>
  The unique identifier of the sequence to delete.
</ParamField>

---

## Response

### 200 — Success

Returns a confirmation message indicating the sequence was deleted.

<ResponseField name="msg" type="string">
  A confirmation string. Always `"Sequence deleted"` on success.
</ResponseField>

```json Example Response
{
  "msg": "Sequence deleted"
}
```

### Error Responses

| Status | Meaning |
|--------|---------|
| `401`  | Authentication failed — your `X-API-Key` is missing or invalid. |
| `403`  | Forbidden — you do not have permission to delete this sequence. |
| `404`  | Not found — no sequence exists with the provided `sequenceId`. |

All errors return a JSON body: `{"error": "descriptive message"}`

---

## Example

### Delete a Sequence (cURL)

```bash
curl -X DELETE https://api.parallellabs.app/api/v0/sequences/seq_01hx9abc123 \
  -H "X-API-Key: YOUR_API_KEY"
```
