Parallel AI exposes a **Model Context Protocol (MCP) server** that allows AI assistants — such as Claude Desktop, Cursor, and others — to discover and call any Parallel AI API action in real time. The server implements the [MCP Streamable HTTP Transport](https://spec.modelcontextprotocol.io/specification/2025-03-26/basic/transports/#streamable-http) using JSON-RPC 2.0.

For setup instructions with Claude Desktop, Cursor, and other MCP-compatible clients, see the [MCP Integration Guide](/integrations/mcp).

## MCP Server URL

```
https://api.parallellabs.app/api/v0/mcp
```

## Authentication

All MCP requests require authentication. Include your API key using either of the following headers:

```
X-API-Key: YOUR_API_KEY
```
```
Authorization: Bearer YOUR_API_KEY
```

---

## Server Endpoints

The MCP server exposes three HTTP endpoints for discovery and execution.

### GET /api/v0/mcp/info

Returns metadata about the MCP server, its version, and the capabilities it advertises.

```bash
curl -X GET "https://api.parallellabs.app/api/v0/mcp/info" \
  -H "X-API-Key: YOUR_API_KEY"
```

### GET /api/v0/mcp/tools/list

Returns the full list of MCP tools available on this server. Each tool includes its name, description, and input schema.

```bash
curl -X GET "https://api.parallellabs.app/api/v0/mcp/tools/list" \
  -H "X-API-Key: YOUR_API_KEY"
```

### POST /api/v0/mcp/tools/call

Executes a specific MCP tool by name, passing a JSON-RPC 2.0 request body.

```bash
curl -X POST "https://api.parallellabs.app/api/v0/mcp/tools/call" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "jsonrpc": "2.0",
    "id": 1,
    "method": "tools/call",
    "params": {
      "name": "platform_list_capabilities",
      "arguments": {}
    }
  }'
```

## Available Tools

The MCP server provides three tools that together give an AI assistant full access to the Parallel AI platform:

| Tool | Description |
|------|-------------|
| `platform_list_capabilities` | Browse all available API endpoints grouped by category. Use this to discover what actions are available. |
| `platform_get_action_details` | Retrieve the full specification — parameters, headers, and expected response — for a specific endpoint. |
| `platform_execute_action` | Execute any Parallel AI API endpoint directly, passing the required parameters and receiving the response. |

---

## Tool Examples

### platform_list_capabilities

Browse API endpoints organized by category (e.g. documents, audio, browser tasks):

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "method": "tools/call",
  "params": {
    "name": "platform_list_capabilities",
    "arguments": {}
  }
}
```

**Example response:**

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "categories": [
      {
        "name": "documents",
        "actions": ["list_documents", "create_document", "get_document", "delete_document"]
      },
      {
        "name": "audio",
        "actions": ["list_audio", "create_audio", "list_voices", "list_models", "delete_audio"]
      },
      {
        "name": "browser",
        "actions": ["submit_browser_task", "get_browser_task_status", "cancel_browser_task"]
      }
    ]
  }
}
```

---

### platform_get_action_details

Get the full spec for a specific API action before executing it:

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "method": "tools/call",
  "params": {
    "name": "platform_get_action_details",
    "arguments": {
      "action": "create_document"
    }
  }
}
```

**Example response:**

```json
{
  "jsonrpc": "2.0",
  "id": 2,
  "result": {
    "action": "create_document",
    "method": "POST",
    "path": "/api/v0/documents",
    "parameters": {
      "name": { "type": "string", "required": true },
      "content": { "type": "string", "required": false },
      "folder": { "type": "string", "required": false, "default": "/" },
      "fileUrl": { "type": "string", "required": false }
    }
  }
}
```

---

### platform_execute_action

Execute any Parallel AI API endpoint with the specified parameters:

```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "method": "tools/call",
  "params": {
    "name": "platform_execute_action",
    "arguments": {
      "action": "create_document",
      "parameters": {
        "name": "Return Policy",
        "content": "All returns must be requested within 30 days of purchase.",
        "folder": "/support"
      }
    }
  }
}
```

**Example response:**

```json
{
  "jsonrpc": "2.0",
  "id": 3,
  "result": {
    "id": "doc_01hx4p7q8r",
    "name": "Return Policy",
    "content": "All returns must be requested within 30 days of purchase.",
    "fileUrl": "",
    "folder": "/support",
    "created": "2024-04-10T12:00:00Z",
    "updated": "2024-04-10T12:00:00Z"
  }
}
```
