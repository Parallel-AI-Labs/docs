Permanently delete an API key. The key will stop authenticating requests **immediately** after deletion. Any services or integrations using this key will lose access right away.

<Warning>
  Deleting an API key is **immediate and irreversible**. All services using this key will lose access instantly. Make sure you have rotated to a new key in all affected systems before deleting the old one.
</Warning>

## Endpoint

```
DELETE https://api.parallellabs.app/api/v0/api_keys
```

## Authentication

Include your API key in the request header:

```
X-API-Key: YOUR_API_KEY
```

## Request Body

<ParamField body="companyId" type="string" required>
  The ID of the company the key belongs to.
</ParamField>

<ParamField body="name" type="string" required>
  The name of the API key to delete.
</ParamField>

## Response

### 200 — Success

Returns a confirmation that the key was deleted.

```json
{
  "msg": "API key deleted"
}
```

### Error Responses

| Status | Description |
|--------|-------------|
| `401`  | Missing or invalid API key. |
| `500`  | Internal server error. |

Error responses follow the format:

```json
{ "error": "message" }
```

## Example Request

```bash
curl -X DELETE "https://api.parallellabs.app/api/v0/api_keys" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "companyId": "comp_01hx8t1u5v",
    "name": "production-server"
  }'
```

## Example Response

```json
{
  "msg": "API key deleted"
}
```
