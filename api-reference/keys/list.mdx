Retrieve all API keys associated with your account. Use the optional `companyId` parameter to filter results to keys belonging to a specific company.

## Endpoint

```
GET https://api.parallellabs.app/api/v0/api_keys
```

## Authentication

Include your API key in the request header:

```
X-API-Key: YOUR_API_KEY
```

## Query Parameters

<ParamField query="companyId" type="string">
  Optional. Filter returned keys to those belonging to a specific company.
</ParamField>

## Response

### 200 — Success

<ResponseField name="apiKey" type="string">
  The API key value(s) associated with your account and optional company filter.
</ResponseField>

### Error Responses

| Status | Description |
|--------|-------------|
| `401`  | Missing or invalid API key. |
| `500`  | Internal server error. |

Error responses follow the format:

```json
{ "error": "message" }
```

## Example Request

```bash
curl -X GET "https://api.parallellabs.app/api/v0/api_keys?companyId=comp_01hx8t1u5v" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Example Response

```json
{
  "apiKey": "pk_live_abc123xyz456"
}
```
