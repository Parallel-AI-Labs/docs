Permanently delete a generated audio file from your account. Once deleted, the file can no longer be retrieved from the playback endpoint.

<Warning>
  This action is **irreversible**. The audio file and its associated data are permanently deleted and cannot be recovered. Ensure you no longer need the file before deleting it.
</Warning>

## Endpoint

```
DELETE https://api.parallellabs.app/api/v0/audio/{audioId}
```

## Authentication

Include your API key in the request header:

```
X-API-Key: YOUR_API_KEY
```

## Path Parameters

<ParamField path="audioId" type="string" required>
  The unique identifier of the audio file to delete.
</ParamField>

## Response

### 200 — Success

<ResponseField name="msg" type="string">
  A confirmation string: `"Audio deleted"`.
</ResponseField>

### Error Responses

| Status | Description |
|--------|-------------|
| `401`  | Missing or invalid API key. |
| `403`  | Your account does not have permission to delete this audio file. |
| `404`  | No audio file found with the specified ID. |
| `500`  | Internal server error. |

Error responses follow the format:

```json
{ "error": "message" }
```

## Example Request

```bash
curl -X DELETE "https://api.parallellabs.app/api/v0/audio/aud_01hx5q8r2s" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Example Response

```json
{
  "msg": "Audio deleted"
}
```
