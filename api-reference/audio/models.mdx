Retrieve the list of available text-to-speech models along with their capabilities, limits, and cost information. This is a **public endpoint** — no API key is required. Use the returned `id` values in the `model` field when calling [Create Audio](/api-reference/audio/create).

## Endpoint

```
GET https://api.parallellabs.app/api/v0/audio/models
```

## Authentication

No authentication is required for this endpoint.

## Response

### 200 — Success

Returns an object containing available audio model definitions.

<ResponseField name="id" type="string">
  The model identifier. Pass this as the `model` field when creating audio (e.g. `"eleven_flash_v2_5"`).
</ResponseField>

<ResponseField name="name" type="string">
  The human-readable name of the model.
</ResponseField>

<ResponseField name="description" type="string">
  A description of the model's strengths and intended use cases.
</ResponseField>

<ResponseField name="provider" type="string">
  The model provider. Currently `"elevenlabs"`.
</ResponseField>

<ResponseField name="category" type="string">
  The model category. Always `"speech"` for audio models.
</ResponseField>

<ResponseField name="character_limit" type="integer">
  Maximum number of characters the model can process in a single request.
</ResponseField>

<ResponseField name="cost_credits" type="number">
  The number of credits charged per use.
</ResponseField>

<ResponseField name="duration_minutes" type="number">
  Estimated output duration in minutes per request, based on average input length.
</ResponseField>

### Error Responses

| Status | Description |
|--------|-------------|
| `500`  | Internal server error. |

Error responses follow the format:

```json
{ "error": "message" }
```

## Example Request

No API key is needed for this request:

```bash
curl -X GET "https://api.parallellabs.app/api/v0/audio/models"
```

```json
{
  "id": "eleven_flash_v2_5",
  "name": "Eleven Flash v2.5",

  "duration_minutes": 0.5

```
