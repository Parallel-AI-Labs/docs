Retrieve a paginated list of all audio files generated for your company. Each record includes the original text, the voice and model used, the output format, and a URL to the generated file. Use this endpoint to audit or replay previously generated audio.

## Endpoint

```
GET https://api.parallellabs.app/api/v0/audio
```

## Authentication

Include your API key in the request header:

```
X-API-Key: YOUR_API_KEY
```

## Query Parameters

<ParamField query="companyId" type="string">
  Optional company ID to scope results to a specific company. If omitted, results are scoped to the company associated with your API key.
</ParamField>

<ParamField query="page" type="integer" default="1">
  The page number to retrieve. Starts at `1`.
</ParamField>

<ParamField query="pageSize" type="integer" default="10">
  Number of audio records to return per page.
</ParamField>

## Response

### 200 — Success

Returns a paginated list of audio objects.

<ResponseField name="items" type="array">
  Array of audio objects.

  <Expandable title="Audio object fields">
    <ResponseField name="id" type="string">
      Unique identifier for the audio file.
    </ResponseField>

    <ResponseField name="text" type="string">
      The source text that was converted to speech.
    </ResponseField>

    <ResponseField name="voiceId" type="string">
      The ElevenLabs voice ID used to generate the audio.
    </ResponseField>

    <ResponseField name="model" type="string">
      The ElevenLabs model used (e.g. `"eleven_flash_v2_5"`).
    </ResponseField>

    <ResponseField name="format" type="string">
      The audio format of the output file (e.g. `"mp3"`).
    </ResponseField>

    <ResponseField name="duration" type="number">
      Duration of the audio file in seconds.
    </ResponseField>

    <ResponseField name="url" type="string">
      URL to stream or download the generated audio file.
    </ResponseField>

    <ResponseField name="created" type="string">
      ISO 8601 timestamp of when the audio was generated.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="total" type="integer">
  Total number of audio files matching the query (across all pages).
</ResponseField>

<ResponseField name="page" type="integer">
  The current page number.
</ResponseField>

<ResponseField name="pageSize" type="integer">
  The number of items per page used for this response.
</ResponseField>

### Error Responses

| Status | Description |
|--------|-------------|
| `401`  | Missing or invalid API key. |
| `403`  | Your account does not have permission to access this resource. |
| `500`  | Internal server error. |

Error responses follow the format:

```json
{ "error": "message" }
```

## Example Request

```bash
curl -X GET "https://api.parallellabs.app/api/v0/audio?page=1&pageSize=10" \
  -H "X-API-Key: YOUR_API_KEY"
```
