Retrieve the complete content and metadata for a single document in your knowledge base by its unique ID. This is useful for inspecting document contents or verifying what your agents have access to.

## Endpoint

```
GET https://api.parallellabs.app/api/v0/documents/{documentId}
```

## Authentication

Include your API key in the request header:

```
X-API-Key: YOUR_API_KEY
```

## Path Parameters

<ParamField path="documentId" type="string" required>
  The unique identifier of the document to retrieve.
</ParamField>

## Response

### 200 — Success

Returns the full document object.

<ResponseField name="id" type="string">
  Unique identifier for the document.
</ResponseField>

<ResponseField name="name" type="string">
  The display name of the document.
</ResponseField>

<ResponseField name="content" type="string | null">
  The full text content of the document, or `null` if the document is file-based.
</ResponseField>

<ResponseField name="fileUrl" type="string">
  URL pointing to the stored file. Empty string if the document is text-only.
</ResponseField>

<ResponseField name="folder" type="string">
  The folder path the document belongs to.
</ResponseField>

<ResponseField name="created" type="string">
  ISO 8601 timestamp of when the document was created.
</ResponseField>

<ResponseField name="updated" type="string">
  ISO 8601 timestamp of when the document was last updated.
</ResponseField>

### Error Responses

| Status | Description |
|--------|-------------|
| `401`  | Missing or invalid API key. |
| `403`  | Your account does not have permission to access this document. |
| `404`  | No document found with the specified ID. |
| `500`  | Internal server error. |

Error responses follow the format:

```json
{ "error": "message" }
```

## Example Request

```bash
curl -X GET "https://api.parallellabs.app/api/v0/documents/doc_01hx4p7q8r" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Example Response

```json
{
  "id": "doc_01hx4p7q8r",
  "name": "Refund Policy",
  "content": "Our refund policy allows customers to request a full refund within 30 days of purchase. To initiate a refund, contact support@acme.com with your order number.",
  "fileUrl": "",
  "folder": "/support",
  "created": "2024-04-10T12:00:00Z",
  "updated": "2024-04-10T12:00:00Z"
}
```
