Add a new document to your company's knowledge base. Documents can be plain text (via the `content` field) or linked files (via `fileUrl`). Once uploaded, agents with knowledge base access will automatically incorporate the document's content when answering relevant questions.

## Endpoint

```
POST https://api.parallellabs.app/api/v0/documents
```

## Authentication

Include your API key in the request header:

```
X-API-Key: YOUR_API_KEY
```

## Request Body

Send a JSON body with the following fields:

<ParamField body="name" type="string" required>
  A display name for the document. Used to identify it in your knowledge base.
</ParamField>

<ParamField body="content" type="string">
  The full text content of the document. Use this field for plain-text documents. Either `content` or `fileUrl` should be provided.
</ParamField>

<ParamField body="folder" type="string" default="/">
  The folder path to organize the document under (e.g. `"/support"`, `"/hr/policies"`). Defaults to the root folder `"/"`.
</ParamField>

<ParamField body="fileUrl" type="string">
  A publicly accessible URL pointing to a file (e.g. a PDF or DOCX). Use this as an alternative to `content` for file-based documents.
</ParamField>

## Response

### 201 — Created

Returns the newly created document object.

<ResponseField name="id" type="string">
  Unique identifier for the document.
</ResponseField>

<ResponseField name="name" type="string">
  The display name of the document.
</ResponseField>

<ResponseField name="content" type="string | null">
  The text content of the document, or `null` if the document is file-based.
</ResponseField>

<ResponseField name="fileUrl" type="string">
  URL pointing to the stored file. Empty string if the document is text-only.
</ResponseField>

<ResponseField name="folder" type="string">
  The folder path the document was saved to.
</ResponseField>

<ResponseField name="created" type="string">
  ISO 8601 timestamp of when the document was created.
</ResponseField>

<ResponseField name="updated" type="string">
  ISO 8601 timestamp of when the document was last updated.
</ResponseField>

### Error Responses

| Status | Description |
|--------|-------------|
| `400`  | Invalid or missing required fields. |
| `401`  | Missing or invalid API key. |
| `403`  | Your account does not have permission to perform this action. |
| `500`  | Internal server error. |

Error responses follow the format:

```json
{ "error": "message" }
```

## Example Request

```bash
curl -X POST "https://api.parallellabs.app/api/v0/documents" \
  -H "X-API-Key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Refund Policy",
    "content": "Our refund policy allows customers to request a full refund within 30 days of purchase. To initiate a refund, contact support@acme.com with your order number.",
    "folder": "/support"
  }'
```

## Example Response

```json
{
  "id": "doc_01hx4p7q8r",
  "name": "Refund Policy",
  "content": "Our refund policy allows customers to request a full refund within 30 days of purchase. To initiate a refund, contact support@acme.com with your order number.",
  "fileUrl": "",
  "folder": "/support",
  "created": "2024-04-10T12:00:00Z",
  "updated": "2024-04-10T12:00:00Z"
}
```
