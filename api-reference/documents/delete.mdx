Permanently delete a document from your knowledge base. After deletion, your agents will no longer have access to this document's content when generating responses.

<Warning>
  This action is **irreversible**. Once deleted, the document and all its content are permanently removed and cannot be recovered. Make sure you no longer need this document before proceeding.
</Warning>

## Endpoint

```
DELETE https://api.parallellabs.app/api/v0/documents/{documentId}
```

## Authentication

Include your API key in the request header:

```
X-API-Key: YOUR_API_KEY
```

## Path Parameters

<ParamField path="documentId" type="string" required>
  The unique identifier of the document to delete.
</ParamField>

## Response

### 200 — Success

Returns a confirmation message.

<ResponseField name="msg" type="string">
  A confirmation string: `"Document deleted"`.
</ResponseField>

### Error Responses

| Status | Description |
|--------|-------------|
| `401`  | Missing or invalid API key. |
| `403`  | Your account does not have permission to delete this document. |
| `404`  | No document found with the specified ID. |

Error responses follow the format:

```json
{ "error": "message" }
```

## Example Request

```bash
curl -X DELETE "https://api.parallellabs.app/api/v0/documents/doc_01hx4p7q8r" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Example Response

```json
{
  "msg": "Document deleted"
}
```
