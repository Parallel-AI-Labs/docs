Cancel a browser task that is currently `pending` or `running`. This is useful for stopping long-running tasks that are no longer needed. Tasks that have already reached a terminal state (`completed`, `failed`, or `cancelled`) cannot be cancelled.

## Endpoint

```
DELETE https://api.parallellabs.app/api/v0/browser-task/{task_id}
```

## Authentication

Include your API key in the request header:

```
X-API-Key: YOUR_API_KEY
```

## Path Parameters

<ParamField path="task_id" type="string" required>
  The unique ID of the browser task to cancel.
</ParamField>

## Notes

- Only tasks with a status of `"pending"` or `"running"` can be cancelled.
- Attempting to cancel a task in a terminal state (`completed`, `failed`, `cancelled`) will return a `404` error.
- Partial credits may be charged for tasks that were running at the time of cancellation.

## Response

### 200 — Success

Returns a confirmation that the task has been cancelled.

```json
{
  "msg": "Task cancelled"
}
```

### Error Responses

| Status | Description |
|--------|-------------|
| `401`  | Missing or invalid API key. |
| `404`  | No active task found with the specified ID, or the task is already in a terminal state. |
| `500`  | Internal server error. |

Error responses follow the format:

```json
{ "error": "message" }
```

## Example Request

```bash
curl -X DELETE "https://api.parallellabs.app/api/v0/browser-task/btask_01hx6r9s3t" \
  -H "X-API-Key: YOUR_API_KEY"
```

## Example Response

```json
{
  "msg": "Task cancelled"
}
```
