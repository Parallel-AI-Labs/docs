Check the current status of a submitted browser task. Poll this endpoint after submitting a task via [Submit Browser Task](/api-reference/browser/submit). When `status` is `"completed"`, the `result` field will contain the task output.

## Endpoint

```
GET https://api.parallellabs.app/api/v0/browser-task/{task_id}
```

## Authentication

Include your API key in the request header:

```
X-API-Key: YOUR_API_KEY
```

## Path Parameters

<ParamField path="task_id" type="string" required>
  The unique task ID returned when you submitted the browser task.
</ParamField>

## Response

### 200 — Success

<ResponseField name="taskId" type="string">
  The unique identifier of the task.
</ResponseField>

<ResponseField name="status" type="string">
  The current execution status of the task. Possible values:
  - `"pending"` — The task is queued and has not started yet.
  - `"running"` — The browser is actively executing the task.
  - `"completed"` — The task finished successfully. Check the `result` field.
  - `"failed"` — The task encountered an error. Check `errorMessage` for details.
  - `"cancelled"` — The task was cancelled before completion.
</ResponseField>

<ResponseField name="progressMessage" type="string">
  A human-readable description of the task's current step or state.
</ResponseField>

<ResponseField name="createdDate" type="string">
  ISO 8601 timestamp of when the task was submitted.
</ResponseField>

<ResponseField name="startedDate" type="string">
  ISO 8601 timestamp of when the task began executing. `null` if not yet started.
</ResponseField>

<ResponseField name="completedDate" type="string">
  ISO 8601 timestamp of when the task finished. `null` if not yet complete.
</ResponseField>

<ResponseField name="errorMessage" type="string">
  A description of what went wrong. Only present when `status` is `"failed"`.
</ResponseField>

<ResponseField name="result" type="object">
  The task output. Only present when `status` is `"completed"`.

  <Expandable title="Result object fields">
    <ResponseField name="success" type="boolean">
      `true` if the browser task completed its objective successfully.
    </ResponseField>

    <ResponseField name="result" type="string">
      The natural language output or extracted data from the browser task.
    </ResponseField>

    <ResponseField name="history" type="array">
      An ordered list of steps the browser agent took to complete the task.
    </ResponseField>

    <ResponseField name="creditsCharged" type="number">
      The number of credits deducted from your account for this task.
    </ResponseField>
  </Expandable>
</ResponseField>

### Error Responses

| Status | Description |
|--------|-------------|
| `401`  | Missing or invalid API key. |
| `404`  | No task found with the specified ID. |
| `500`  | Internal server error. |

Error responses follow the format:

```json
{ "error": "message" }
```

## Example Request

```bash
curl -X GET "https://api.parallellabs.app/api/v0/browser-task/btask_01hx6r9s3t" \
  -H "X-API-Key: YOUR_API_KEY"
```
